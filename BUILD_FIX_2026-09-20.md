# GitHub Actions build fix

The previous build stopped before compilation because AGP 9.x enables built-in Kotlin by default while this project applies `org.jetbrains.kotlin.kapt`.

The project intentionally uses KAPT for Room annotation processing, so `gradle.properties` now contains:

- `android.builtInKotlin=false`
- `android.newDsl=false`

This is the compatibility bypass recommended by the AGP error itself. No KSP plugin is used.

The GitHub Actions workflow continues to use JDK 17 and Gradle 9.3.1.
