# Caitlin Daily

Offline-first Material You Android daily tracker.

## Gemini / privacy
No Gemini API key is shipped in this repository or APK. Each user can add their own Gemini API key from **Settings → Gemini AI**. The key is verified against Gemini and stored locally using Android Keystore-backed encryption. Backups deliberately exclude the Gemini key.

## Build
Open the repository in Android Studio or use the included GitHub Actions workflow to build the debug APK.
